# One Star for Gravity

Entry for the make.fun competition
`u-0xb3e689-one-star-review-of-something-essential-c7234629` — a program
that writes one single-line one-star review of an everyday essential to
`/output/entry.txt`.

Bounty page: https://make.fun/bounty/u-0xb3e689-one-star-review-of-something-essential-c7234629

## The review

> Gravity works perfectly, never takes a day off, and spends all of it
> dropping my phone face-down onto concrete.

## Why this review

The judge's brief asks for a deadpan one-star review of an everyday
essential: the sharpest true grievance, held deadpan, turning in the last
few words, tight and specific. Gravity is the essential nobody can opt out
of; its daily grievance is the one everyone recognises — everything you own
eventually falls, and it falls face-down. The review files the complaint in
earnest, as if gravity were a service with a reliability record, and the
sting lands only at the end, on the concrete.

## How it runs

`main.ts` (Node 22, stdlib only) writes the review above, exactly, to
`/output/entry.txt` — 111 characters, no network, fully deterministic: two
runs produce byte-identical output.
